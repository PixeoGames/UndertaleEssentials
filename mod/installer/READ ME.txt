UNDERTALE ESSENTIALS  -  test version 0.3.1
===========================================

Undertale kept as close to the original as possible, with only the essentials
added: 60, 120 or more frames per second at the normal game speed, extra
controls, and fixes for bugs that newer versions of Windows brought out.

THIS IS AN EARLY TEST VERSION. Expect bugs and issues.

You need Undertale on Steam (Windows), fully updated.


INSTALL
1. Unzip this first: right-click the zip file > Extract All.
2. In the unzipped folder, double-click  Install.bat
   (If a blue "Windows protected your PC" box appears: click "More info", then "Run anyway".)
3. A window opens. It finds your Undertale folder by itself (if not, click Browse...).
4. Click "Back up my saves" first: it copies your saves to Documents\Undertale save backups.
5. Click Install. When it says "Installed!", you can close the window, or click Play.


PLAY
1. Make sure Steam is running.
2. Double-click  "Undertale Essentials"  on your desktop.

In game:
- F1 opens the mod settings: frame rate, VSync, controls.
- W A S D move, J = confirm, K = cancel, L = menu. The normal keys work too.

The mod uses your normal Undertale save. Back it up first: the installer's
"Back up my saves" button does it, or paste  %LOCALAPPDATA%\UNDERTALE  into the File
Explorer address bar and copy that folder somewhere safe.

Starting Undertale from Steam still plays the normal, unmodded game.

The installer changes one setting in Undertale's options.ini, so the frame rate can go
above your monitor's refresh rate. Uninstalling puts it back.


UNINSTALL
Open Install.bat again and click Uninstall (or double-click  Uninstall.bat  and press
Enter). Your saves are kept.


FOUND A BUG?
Report it on the mod's GitHub page (Issues > New issue > Bug report), or tell the
person who sent you this:
- where you were in the game and what happened,
- your frame rate setting (F1),
- a screenshot or short video if you can.

Installer problems: the installer says what went wrong and what to do. It also keeps
a log for bug reports: click "Copy details for a bug report" in its window, or find
the file  %TEMP%\UndertaleEssentials-installer.log  (paste that into the File
Explorer address bar). If the installer window doesn't open at all, Install.bat
offers to install in its own window instead.
